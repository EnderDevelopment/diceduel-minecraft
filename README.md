# DiceDuel

DiceDuel is a Minecraft plugin that introduces a dice-based combat system. When attacking mobs, the game rolls a d20 against a randomly assigned DC (Difficulty Class) for each mob. The attack roll is determined by the weapon you are wielding: d4 for fists, d6 for wood, d8 for stone, d10 for copper, d12 for iron, d20 for diamond, and 2d20 (highest) for netherite. During the attack, all mobs are frozen, and the DC is displayed above their heads.

## Install

1. Download the DiceDuel plugin JAR file.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. Equip a weapon in your main hand.
2. Attack a mob to roll a dice against its DC.
3. The result of the attack will be displayed in the chat.
